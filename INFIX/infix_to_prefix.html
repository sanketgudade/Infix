Prefix Conversion Algorithm

1Recursive Main-Operator Method

  1. Tokenize the expression into operands, operators, and parentheses
  2. If expression is a single operand, return it
  3. If expression has outer parentheses, remove them
  4. Scan left to right at depth 0 (outside parentheses)
  5. Find the operator with lowest precedence at depth 0
  6. If multiple operators have same precedence:
    • Left-associative: choose the rightmost one
    • Right-associative: choose the leftmost one
  7. Split expression at main operator
  8. Return: operator + prefix(left) + prefix(right)

2Operator Precedence & Associativity

Operator Precedence Associativity
^ (Exponentiation) 4 (Highest) Right
*, / 3 Left
+, - 2 Left

3Example: A+B-C

Step 1: Operators at depth 0: + and - (both precedence 2)

Step 2: Both left-associative → choose rightmost: -

Step 3: Split: L = "A+B", R = "C"

Step 4: Convert L: A+B → main operator + → prefix: +AB

Step 5: Combine: - +AB C → -+ABC
