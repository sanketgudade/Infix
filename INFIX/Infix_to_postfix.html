Postfix Conversion Algorithm

1Stack-Based Algorithm

  1. Initialize an empty stack
  2. Scan the infix expression from left to right
  3. If the scanned character is an operand, add it to output
  4. If the scanned character is '(', push it to the stack
  5. If the scanned character is ')', pop from stack until '(' is encountered
  6. If the scanned character is an operator:
    • While stack is not empty and precedence of operator ≤ precedence of stack top
    • Pop from stack and add to output
    • Push the scanned operator to stack
  7. After scanning, pop all remaining operators from stack

2Operator Precedence & Associativity

Operator Precedence Associativity
^ (Exponentiation) 4 (Highest) Right
*, / 3 Left
+, - 2 Left

3Example: A+B*C

Step 1: A → output: "A"

Step 2: + → push to stack: ["+"]

Step 3: B → output: "AB"

Step 4: * → precedence(3) > precedence(+)=2 → push: ["+", "*"]

Step 5: C → output: "ABC"

Step 6: End → pop all: output becomes "ABC*+"
