Evaluation Algorithm

1Algorithm Steps

  1. Read the prefix expression from right to left
  2. If the symbol is an operand, push it onto the stack
  3. If the symbol is an operator, pop two operands from the stack
  4. Perform the operation on the popped operands
  5. Push the result back onto the stack
  6. Repeat until the entire expression is scanned
  7. The final result will be the only value remaining in the stack

2Operator Precedence

In prefix notation, operators come before their operands, so precedence is handled by the order of operations:

Operator Operation Example
+ Addition + 3 4 → 7
- Subtraction - 5 2 → 3
* Multiplication * 3 4 → 12
/ Division / 8 2 → 4
^ Exponentiation ^ 2 3 → 8

3Example Evaluation

Prefix: - * 2 3 + 4 5

Step-by-step:

  1. Read from right: 5 → push to stack
  2. 4 → push to stack
  3. + → pop 4 and 5, compute 4+5=9, push 9
  4. 3 → push to stack
  5. 2 → push to stack
  6. * → pop 2 and 3, compute 2*3=6, push 6
  7. - → pop 6 and 9, compute 6-9=-3

Result: -3
